# SYSTEM CONTEXT: IOXET Unified Identity Platform
We are building a centralized Identity Provider (IdP) called "IOXET IAM".
**Role:** You are the Lead Backend Architect. Follow these specs strictly.

## Tech Stack
- **Framework:** Django (Python)
- **Database:** PostgreSQL (Primary), Redis (Caching/Auth Codes)
- **Auth Protocol:** OAuth 2.0 with OIDC and PKCE (Proof Key for Code Exchange).
- **Token Type:** Stateless JWT (RS256 signing).

## Core Database Schema (Strict Adherence Required)
1.  **Users Table:**
    -   `id`: UUID (Primary Key, default uuid_v4)
    -   `email`: VARCHAR(255) (Unique, Username field)
    -   `password_hash`: Standard Django Auth
    -   `is_active`, `is_staff`, `date_joined`
2.  **Clients Table (OAuth Applications):**
    -   `client_id`: UUID
    -   `client_secret_hash`: Hashed secret
    -   `redirect_uris`: JSON Array
    -   `algorithm`: VARCHAR (e.g., RS256)
3.  **RefreshTokens Table:**
    -   Links User + Client.
    -   Stores `token_hash` (not plain text).
4.  **Auth Codes (Ephemeral):**
    -   Stored in **Redis**, not Postgres. TTL = 60 seconds.
